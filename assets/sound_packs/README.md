# Receiver-selected sound packs

Each pack folder contains manifest.json. Add audio assets and list paths under sounds (mood ID to multiple clip paths) or songs. The receiver chooses their own pack; messages carry only a mood ID, never a sender-selected audio file. Starter manifests intentionally contain no actual audio. The oops pack reserves oops_fahhh.mp3 for an original or licensed clip. Add attribution and license details before release.
